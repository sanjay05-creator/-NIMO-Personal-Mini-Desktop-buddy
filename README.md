# NIMO – Personal Mini Monitor

NIMO is my first personal electronics project built around an ESP32-C3 SuperMini.

## Controller
- ESP32-C3 SuperMini

## Main Components
- 0.96" SSD1306 OLED 128×64
- DS3231 RTC
- 3.7V 1200mAh Li-ion battery
- USB Type-C charging module
- MT3608 boost converter
- Touch sensor
- Push buttons
- 2-channel relay module
- LEDs and resistors 

## Planned Features
- Digital clock and date
- Animated NIMO face
- Touch wake
- Button-based menu
- Light control
- Wi-Fi / phone control
- Battery-powered operation

## Project Goal

NIMO will start as a personal mini monitor and will be upgraded step-by-step into a more advanced personal assistant device.
